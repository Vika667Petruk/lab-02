**1\. Описание предметной области:**

Аптека — это специализированное медицинское учреждение, которое занимается изготовлением, хранением, контролем качества и отпуском лекарственных препаратов, а также продажей медицинских изделий и других товаров для здоровья. Препараты в аптеку поступают от поставщиков отдельными партиями. Один и тот же препарат может поставляться разными поставщиками и поступать несколькими партиями с различными сроками годности. Каждая партия хранится в определённом месте хранения (стеллаж, шкаф, холодильник) и относится к конкретному препарату и поставщику. Препараты группируются по категориям (например, антибиотики, анальгетики) и выпускаются конкретными производителями. Покупатели приобретают препараты в аптеке. Каждая покупка оформляется как продажа, которая включает одну или несколько позиций продажи. Каждая позиция продажи связана с конкретной партией препарата. Для препаратов, отпуск которых требует рецепта, оформляется рецепт, связанный с покупателем и соответствующим препаратом. Один рецепт может использоваться только в допустимых продажах. Объектами предметной области являются: категории препаратов, препараты, производители, поставщики, партии, места хранения, покупатели, продажи, позиции продажи и рецепты.

**3\. Правила предметной области**

1\. Один препарат относится только к одной категории; в одной категории может быть много препаратов.

2\. Один производитель может выпускать много препаратов; каждый препарат имеет только одного производителя.

3\. Один препарат может поступать несколькими партиями; каждая партия относится только к одному препарату.

4\. Один препарат может поставляться разными поставщиками, и один поставщик может поставлять разные препараты.

5\. Каждая партия относится строго к одному препарату и одному поставщику.

6\. Партия хранится в одном конкретном месте хранения; в одном месте хранения может храниться много партий.

7\. Одна продажа включает одну или несколько товарных позиций.

8\. Каждая позиция продажи связана одновременно с продажей и с конкретной партией препарата.

9\. Один покупатель может совершить много продаж; каждая продажа оформляется на одного покупателя.

10\. Рецепт оформляется на одного покупателя и один препарат.

11\. Один рецепт может использоваться только в допустимых продажах (для препаратов, требующих рецепта).

12\. Препарат, требующий рецепта, не может быть продан без действующего рецепта покупателя.
